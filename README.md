# 茶語時光｜飲料預訂系統原型

管理資訊系統課程作業：可操作的飲料預訂系統原型。不含真實會員、金流與後端，資料只存在使用者自己的瀏覽器中。

- 線上 Demo：https://johnlin10.github.io/drink-order-demo/
- 作業說明：https://johnlin10.github.io/drink-order-demo/#/report
  （系統連結、可演示流程、系統功能介紹、測試紀錄與問題修正、商業價值說明）

## 功能

| 顧客端                                         | 店家端                 |
| ---------------------------------------------- | ---------------------- |
| 菜單分類瀏覽，每款飲料都有等角插圖             | 即時訂單列表           |
| 容量、甜度、冰塊、加料客製化，插圖即時反映     | 一鍵推進製作狀態       |
| 購物車（同規格自動合併、數量增減）             | 訂單數、營業額、客單價 |
| 結帳（姓名與手機驗證、取餐時間、模擬付款）     | 待製作筆數、熱銷排行   |
| 訂單進度追蹤（已接單、製作中、可取餐、已完成） |                        |

- 顧客端與店家端開在不同分頁時，資料即時同步，方便現場演示
- 電腦版標題固定、點餐頁左半邊固定、右半邊捲動；手機版改為底部導覽列
- 按鈕採「實體按鍵」互動：平常是平的、滑鼠移上去浮起、按下時鍵帽下沉、選取只換顏色

## 技術

| 項目    | 使用                                                  |
| ------- | ----------------------------------------------------- |
| 前端    | React 18、TypeScript、React Router                    |
| 建置    | Vite、pnpm                                            |
| 樣式    | SCSS；插圖與紋理以 SVG 手寫，不用圖片檔               |
| 資料    | 瀏覽器 localStorage                                   |
| 測試    | Vitest                                                |
| 部署    | GitHub Actions 自動發布到 GitHub Pages                |
| AI 協作 | 使用 Claude Code 生成程式碼，再由本人檢視、測試與調整 |

## 專案結構

```
src/
  components/   共用元件（飲料插圖、對話框、圖示、數量增減）
  data/         菜單資料、localStorage 狀態
  hooks/        捲動邊緣偵測
  pages/        點餐、我的訂單、店家後台、作業說明
  styles/       斷點與按鍵互動的共用樣式
  utils/        價格與訂單計算、按下狀態
```

## 開發

```bash
pnpm install
pnpm dev        # 本機開發
pnpm test       # 單元測試
pnpm lint       # 程式碼檢查
pnpm build      # 建置到 build/
```

## 部署

push 到 `main` 後，由 `.github/workflows/deploy.yml` 自動測試、建置並發布到 GitHub Pages。
第一次需要到 GitHub repo 的 Settings → Pages → Source 選擇 GitHub Actions。
